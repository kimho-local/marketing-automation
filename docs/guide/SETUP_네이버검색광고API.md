# 네이버 검색광고 API 셋업 가이드

Re:NK 네이버 SA 데이터 자동 수집을 위한 API 연동 가이드입니다.

---

## 1단계: 네이버 검색광고 센터 접속

1. https://searchad.naver.com 접속
2. Re:NK 광고계정으로 로그인

---

## 2단계: API 키 발급

1. 좌측 메뉴 → **도구** → **API 관리** 클릭
2. **API 라이선스 관리** 탭 선택
3. **API Key 발급** 버튼 클릭
4. 아래 3가지 값을 메모

| 항목 | 설명 | 예시 |
|------|------|------|
| **고객번호 (Customer ID)** | 광고계정 고유번호 (대시보드 우측 상단에 표시) | 1234567 |
| **API Key (Access License)** | API 접근용 공개키 | 0100000000abcdef... |
| **Secret Key** | API 서명용 비밀키 (발급 시 1회만 표시) | abcdefghijk... |

> Secret Key는 발급 시 한 번만 보여줍니다. 반드시 바로 복사해 두세요.
> 분실 시 기존 키를 삭제하고 재발급해야 합니다.

---

## 3단계: 인증 파일 생성

프로젝트 폴더(`valen_brandmarketing_Team1_AI.Assistant`)에 아래 파일을 생성합니다.

파일명: **`renk_naver_credentials.json`**

```json
{
  "search_ad": {
    "customer_id": "여기에_고객번호_입력",
    "api_key": "여기에_API_Key_입력",
    "secret_key": "여기에_Secret_Key_입력"
  }
}
```

> 메모장으로 작성 → 파일명을 `renk_naver_credentials.json`으로 저장
> 저장 시 "파일 형식"을 "모든 파일(*.*)"로 선택해야 .json 확장자가 정확히 들어갑니다.

---

## 4단계: 연결 테스트

CMD에서 실행:

```
python naver_api_fetcher.py --test
```

성공 시 출력:
```
✓ 인증정보 로드 완료
  고객번호: 1234567
✓ 캠페인 3개 조회 성공
  - [파워링크] Re:NK 파워링크
  - [브랜드검색] Re:NK 브랜드검색
  - [쇼핑검색] Re:NK 쇼핑검색
```

## 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| `naver_credentials.json 파일 없음` | 인증 파일 미생성 | 3단계 참고하여 파일 생성 |
| `HTTP 401` | API Key 또는 Secret Key 오류 | 키 재확인, 공백 없는지 확인 |
| `HTTP 403` | 고객번호 불일치 또는 권한 없음 | 검색광고 센터에서 해당 계정의 API 권한 확인 |
| `캠페인 조회 실패` | 계정에 캠페인이 없거나 API 미활성 | 검색광고 센터 → 도구 → API 관리에서 상태 확인 |
