META Marketing API 셋업 가이드

발렌라이프 비즈니스 포트폴리오 → 리엔케이 광고 계정 자동화를 위한 준비사항

0 전체 흐름 미리보기

아래 4단계를 순서대로 완료하면, Cowork에서 매일 자동으로 META 데이터를 가져올 수 있습니다.

🏢
STEP 1. Meta 비즈니스 설정에서 앱 만들기
👤
STEP 2. 시스템 사용자 만들고 권한 부여
🔑
STEP 3. 액세스 토큰 발급받기
🆔
STEP 4. 광고 계정 ID 2개 확인하기
소요 시간: 약 15~20분

모두 Meta 비즈니스 설정 페이지(business.facebook.com)에서 진행합니다. 비용은 없습니다.

1 Meta 앱 만들기

광고 데이터를 API로 가져오려면, "앱"이라는 통로가 하나 필요합니다.

1-1. 비즈니스 설정 접속

business.facebook.com/settings 접속 → 발렌라이프 비즈니스 포트폴리오 선택

1-2. 앱 만들기

왼쪽 메뉴에서 계정 → 앱 클릭 → "추가" 버튼 → "새 앱 만들기"

1-3. 앱 유형 선택

사용 사례: "기타" 선택 → 앱 유형: "비즈니스" 선택

1-4. 앱 이름 설정

앱 이름: ReNK-AutoReport (원하는 이름으로 변경 가능)
비즈니스 포트폴리오: 발렌라이프 선택 → "앱 만들기" 클릭

⚠️ 권한 확인

앱을 만들려면 발렌라이프 비즈니스 포트폴리오의 관리자(Admin) 권한이 필요합니다. 권한이 없다면 관리자에게 요청하세요.

2 시스템 사용자 만들기

"시스템 사용자"는 사람이 아닌 프로그램(Cowork)이 대신 로그인하는 전용 계정입니다. 개인 계정 토큰보다 안전하고 만료되지 않습니다.

2-1. 시스템 사용자 메뉴

비즈니스 설정 → 왼쪽 메뉴 사용자 → 시스템 사용자

2-2. 새 시스템 사용자 추가

"추가" 버튼 → 이름: cowork-report-bot → 역할: "관리자" 선택

2-3. 광고 계정 할당 (중요!)

"자산 할당" 클릭 → "광고 계정" 탭 선택 →
리엔케이 스마트스토어 계정과 자사몰 계정 둘 다 체크 →
권한: "보고서 보기"만 체크하면 충분 → "변경사항 저장"

왜 "관리자"로 만드나요?

시스템 사용자 자체의 역할이 관리자여야 자산 할당이 원활합니다. 실제 광고 계정에는 "보고서 보기" 권한만 부여하므로 광고를 수정하거나 삭제할 수는 없습니다. 안전합니다.

3 액세스 토큰 발급

이 토큰이 바로 Cowork가 META 서버에 "나 발렌라이프 소속인데, 리엔케이 광고 데이터 좀 볼게"라고 말할 때 쓰는 열쇠입니다.

3-1. 토큰 생성

시스템 사용자 목록에서 방금 만든 cowork-report-bot 클릭 → "새 토큰 생성"

3-2. 앱 선택

STEP 1에서 만든 앱 ReNK-AutoReport 선택

3-3. 권한 선택 (2개만 체크)

✅ ads_read — 광고 데이터 읽기
✅ read_insights — 성과 리포트 데이터 읽기

나머지는 전부 체크 해제 → "토큰 생성" 클릭

3-4. 토큰 복사 및 보관 ⭐

화면에 표시되는 긴 문자열이 토큰입니다. 이 화면을 닫으면 다시 볼 수 없으니, 반드시 복사하여 안전한 곳에 저장하세요.

⚠️ 토큰 보안 주의

이 토큰은 비밀번호와 같습니다. Slack이나 이메일로 공유하지 마세요. Cowork에 전달할 때도 채팅에 직접 붙여넣기만 하면 됩니다(저장되지 않음).

4 광고 계정 ID 확인

리엔케이 광고 계정 2개의 ID가 필요합니다. act_로 시작하는 숫자입니다.

4-1. 확인 방법 (비즈니스 설정)

비즈니스 설정 → 계정 → 광고 계정 → 리엔케이 관련 계정 2개를 각각 클릭하면 광고 계정 ID가 표시됩니다.

4-2. 또는 Ads Manager에서 확인

Meta Ads Manager 접속 → 상단 계정 선택 드롭다운 → 계정명 옆에 표시되는 숫자가 ID

필요한 ID 정리

구분계정명 (예시)필요한 값
스마트스토어용리엔케이_스마트스토어act_XXXXXXXXXX
자사몰용리엔케이_자사몰act_YYYYYYYYYY

✓ 최종 체크리스트

아래 4가지를 Cowork 채팅에 전달해주시면, 바로 API 자동화를 연결합니다.

  • ☐
    액세스 토큰
    STEP 3에서 발급받은 긴 문자열. EAAxxxxxxx... 형태
    필수
  • ☐
    스마트스토어 광고 계정 ID
    STEP 4에서 확인. act_XXXXXXXXXX 형태
    필수
  • ☐
    자사몰 광고 계정 ID
    STEP 4에서 확인. act_YYYYYYYYYY 형태
    필수
  • ☐
    앱 ID (선택)
    앱 대시보드 상단에 표시. 토큰 검증용으로 있으면 좋음
    선택

→ 전달 후 Cowork가 하는 일

위 정보를 전달해주시면, 아래 과정이 모두 자동화됩니다.

토큰 유효성 검증 — 토큰이 정상 작동하는지, 광고 계정 접근이 되는지 자동 확인
📊
API 데이터 자동 수집 — 매일 전일 META 광고 데이터(광고비, 매출, 노출, 클릭, 구매)를 자동 호출
📝
리포트 자동 기입 — 수집된 데이터를 기존 리포트 양식에 맞춰 자동 반영 + 파생지표 계산
